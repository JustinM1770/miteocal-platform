# backend

API en Node.js y Cloud Functions de MiTeocal.

Responsabilidades:

- API REST para la app móvil y el panel de administración.
- Reglas de seguridad de Firestore y Storage.
- Cloud Functions: notificaciones push por colonia (agua, basura, cierres), generación de
  folios de reporte ciudadano y emisión de pases digitales de la feria.
- Integraciones: Google Maps Platform y pasarela de pago para predial y agua.
