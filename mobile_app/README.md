# mobile_app

Aplicación Flutter de MiTeocal para iOS y Android.

Navegación principal en cuatro pestañas — Inicio, Noticias, Comercio y Servicios — más los
flujos de Feria de Noviembre y Paisanos. El onboarding registra nombre, dirección y colonia,
y verifica el teléfono con un código de 4 dígitos.

`firebase_options.dart`, `google-services.json` y `GoogleService-Info.plist` se generan
localmente con `flutterfire configure` y **no** se versionan.

Sin código todavía. Ver la [guía de puesta en marcha](../README.md#aplicación-móvil).
