# admin_panel

Panel web de administración para el personal del municipio.

Permite publicar noticias y avisos, actualizar el estado del agua y las rutas de basura,
registrar cierres viales y obras, atender los reportes ciudadanos por folio, moderar el
directorio de comercios y administrar la cartelera de la feria.

Acceso restringido por rol mediante custom claims de Firebase Auth.

Sin código todavía. Ver la [guía de puesta en marcha](../README.md#panel-de-administración).
